# BLAXIN Episodic Memory

## Mission
Remember important completed or failed task episodes so future tasks can benefit from prior experience.

## Episode Structure
Store:
- objective
- environment
- strategy
- important actions
- result
- verification
- failures
- recovery
- lessons

Do not store unnecessary raw transcripts.

## Useful Episode
An episode should answer:
- what was the task?
- what worked?
- what failed?
- why?
- what should happen next time?

## Privacy
Strip:
- credentials
- tokens
- private keys
- unnecessary personal data
- raw sensitive tool output

## Retrieval
Retrieve episodes by semantic relevance and task similarity.

## Confidence
Higher confidence for:
- directly observed
- recently verified
- repeatedly successful

Lower confidence for:
- inferred
- outdated
- single unverified episode

## Hard Rules
Memory is evidence, not truth.
Revalidate environment-dependent information before acting.
